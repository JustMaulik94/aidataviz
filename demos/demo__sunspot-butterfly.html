Heliographic latitude of sunspot groups vs. time. Data: Royal Greenwich Observatory / NOAA.

Before — Annual Sunspot Count Line Chart

Annual mean sunspot number, 1878–2019. The ~11-year Schwabe cycle is visible, but all latitude information — the key "butterfly" pattern showing where on the Sun spots appear — is lost by aggregating to a scalar count. This is a common reduction: the time series discards the spatial structure that gives the butterfly diagram its scientific value.

After — Latitude Heatmap (Butterfly Diagram)

Butterfly diagram of sunspot heliographic latitude, 1878–2019. Each column is one calendar year; each row is a 2° latitude bin. Color encodes sunspot group density (sparse = light, dense = dark orange). The classic "butterfly" pattern is immediately visible: at cycle start, spots appear at mid-latitudes (±30°); they migrate toward the equator over 11 years, then a new cycle begins at higher latitudes. The line chart above shows the same data aggregated to a single count — the butterfly structure is invisible there.

What the skill changed

  • Dimensionality rescued. The line chart shows 1-D (SSN vs. time). The butterfly diagram shows 3-D (year × latitude × density). The same data, radically different information content.
  • Heatmap encodes density as color value. Cell brightness encodes sunspot density within each 2° latitude bin per year. This uses a perceptually ordered single-hue scale (light → dark orange) rather than a rainbow.
  • Spörer's law made visible. The diagonal drift of the butterfly wings from high-latitude at cycle start to low-latitude at cycle end — invisible in the line chart — appears immediately in the heatmap.
  • Solar cycle boundaries annotated directly. Cycle numbers appear above the data as small inline labels; no separate legend is needed.
  • Range frame instead of chart box. Two axis lines span the data range; the full border is gone.
  • Equator reference line only. One dashed line at 0° latitude; no horizontal grid lines competing with the data.
  • No legend for cycles. Inline labels ("C12", "C13", …) annotate each cycle directly above its columns.
